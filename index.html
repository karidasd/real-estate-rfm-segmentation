Πώς μεταφράστηκε το κλασικό RFM στο Real Estate

R — Recency (Πρόσφατη κίνηση)

Ημέρες από την τελευταία εισερχόμενη επαφή του πελάτη (αγνοώντας τα δικά μας follow-ups). Ορίζει τα 4 χρονικά παράθυρα (0–60, 61–180, 181–365, 365+).

F — Frequency (Σήματα & Επίσκεψη)

Αριθμός αιτημάτων/επικοινωνιών (2–3 ή 4+ σήματα) και η επίσκεψη σε ακίνητο ως ισχυρό σήμα πρόθεσης αγοράς.

M — Monetary (Budget)

Το δηλωμένο budget (≥ 200.000€) λειτουργεί ως επιταχυντής: αρκούν 2–3 σήματα για να θεωρηθεί «Έτοιμος αγοραστής».

🗄️ Η λογική σε SQL

WITH inbound_activity AS (
  SELECT
    lead_id,
    MAX(event_date) AS last_inbound_date,
    COUNT(*)        AS signals_count,
    MAX(CASE WHEN event_type = 'property_visit'
             THEN 1 ELSE 0 END) AS has_visit
  FROM sample_interactions
  WHERE direction = 'inbound' -- Αγνοούμε τα δικά μας!
  GROUP BY lead_id
)
SELECT
  l.lead_id, l.full_name, l.budget,
  CASE
    WHEN days_since_inbound <= 60 AND (
      has_visit = 1
      OR signals_count >= 4
      OR (signals_count BETWEEN 2 AND 3 AND budget >= 200000)
    ) THEN 'Έτοιμος αγοραστής'
    WHEN days_since_inbound <= 60  THEN 'Νέος ενδιαφερόμενος'
    WHEN days_since_inbound <= 180 THEN 'Σε σκέψη'
    WHEN days_since_inbound <= 365 THEN 'Σε ψύξη'
    ELSE 'Σε νάρκη'
  END AS segment
FROM sample_crm_leads l
LEFT JOIN inbound_activity a ON l.lead_id = a.lead_id;

🐍 Η λογική σε Python

def classify_lead(days, signals, has_visit, budget):
    if days <= 60:
        is_ready = (
            has_visit
            or signals >= 4
            or (2 <= signals <= 3 and budget >= 200_000)
        )
        return "Έτοιμος αγοραστής" if is_ready else "Νέος ενδιαφερόμενος"

    if days <= 180:
        return "Σε σκέψη"
    if days <= 365:
        return "Σε ψύξη"
    return "Σε νάρκη"
